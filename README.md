### Featured Engineering Systems

#### 01. OmniConvert — Client-Side Multi-Format Conversion Engine
> **Zero-Server Uploads • Complete Client Privacy • Sandboxed WebAssembly**
- **Architecture**: In-browser media transcoding and text extraction sandbox powered by **FFmpeg WASM** and **Tesseract OCR**, orchestrated via parallel Web Workers.
- **Key Capabilities**: Transcodes and converts 56+ media formats (Images, Audio, Video, Documents, PDF, OCR) directly inside client RAM with zero server egress.
- **Stack**: `Next.js 16` • `React 19` • `TypeScript` • `WebAssembly` • `Web Workers`
- **Access**: [🌐 Launch WebApp](https://omniconvert-mu.vercel.app) &nbsp;&bull;&nbsp; [📁 Repository Source](https://github.com/Ilmialfa/OmniConvert)

#### 02. FinSight AI — Predictive Financial Intelligence Platform
> **Automated Expense Classification • Structured JSON AI • Recharts**
- **Architecture**: Real-time financial telemetry dashboard utilizing **OpenAI Structured Outputs** (strict JSON schema) for deterministic classification.
- **Key Capabilities**: Sub-second cashflow modeling, dynamic spending trajectory projections, and interactive financial charts built with Recharts.
- **Stack**: `Next.js 16 (Turbopack)` • `React 19` • `TypeScript` • `OpenAI SDK` • `Tailwind CSS`
- **Access**: [🌐 Launch WebApp](https://finsight-ai-vert.vercel.app) &nbsp;&bull;&nbsp; [📁 Repository Source](https://github.com/Ilmialfa/finsight-ai)

#### 03. Website Batik KKN — Cultural Heritage & Commerce System
> **Indigenous Riau Motif Archive • High-Throughput Backoffice**
- **Architecture**: Modernized monolith combining **Laravel 12** backend services with an **Inertia.js React** single-page frontend.
- **Key Capabilities**: Curated cultural motif encyclopedia, granular administrative management via **Filament PHP**, and direct UMKM sales channel.
- **Stack**: `Laravel 12` • `PHP 8.3` • `Inertia.js React` • `Filament PHP` • `MySQL`
- **Access**: [📁 Repository Source](https://github.com/Ilmialfa/website-batik-kkn)

#### 04. Toko Putera Kembar — Retail POS & Inventory Engine
> **High-Velocity Cashier Terminal • Multi-Tier Spatie RBAC**
- **Architecture**: Sub-second transaction processing engine with transactional database safeguards and role isolation.
- **Key Capabilities**: Fast cashier checkout workflow, inventory tracking with low-stock warnings, and strict multi-tier permissions (Owner, Cashier, Warehouse).
- **Stack**: `Laravel 12` • `Spatie RBAC` • `Blade / Tailwind CSS` • `MySQL`
- **Access**: [📁 Repository Source](https://github.com/Ilmialfa/toko-putera-kembar)
