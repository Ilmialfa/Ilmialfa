## About Me

I am an Informatics Engineering student at **Universitas Muhammadiyah Riau (UMRI)** and a full-stack web developer based in Pekanbaru, Indonesia.

I engineer modern web applications with an emphasis on **local-first processing**, **clean architectures**, and **high-performance client-side runtimes**. My core development centers on **Laravel 12**, **Next.js 16**, **React 19**, and **TypeScript**, with dedicated focus on running heavy workloads directly in-browser via **WebAssembly (WASM)** for maximum privacy and zero latency.
